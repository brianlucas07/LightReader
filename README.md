# LightReader

O **LightReader** é um leitor de livros digitais focado no formato **EPUB**, projetado para proporcionar uma experiência de leitura leve, rápida e agradável.

## 📖 Sobre o Projeto

O LightReader tem como objetivo oferecer uma visualização intuitiva, fluida e eficiente para leitura de e-books no formato `.epub`.
